# Работа с базами данных SQL, NoSQL

Работа с базой данных интернет-магазина demoshopping.ru.

| Раздел | Что внутри |
|---|---|
| SELECT in MySQL| Фильтрация и поиск, Сортировка и уникальность, Агрегация и группировка, Объединение и логика |
| Join in MySQL | Фильтрация и поиск, Сортировка и уникальность, Агрегация и группировка, Объединение и подзапросы, Условная логика |
| MongoDB |  Управление БД и данными, Выборка и проекция, Фильтрация и операторы сравнения, Агрегация и подсчет |


**Итог:**
* **MySQL (SQL):** писать запросы на выборку (`SELECT`), фильтрацию (`WHERE`, `LIKE`, `IN`, `BETWEEN`), сортировку (`ORDER BY`) и агрегацию данных (`GROUP BY`, `HAVING`, `SUM`, `AVG`), объединять таблицы (`INNER/LEFT/RIGHT JOIN`, `UNION`), а также использовать подзапросы и условную логику (`CASE`).
* **MongoDB (NoSQL):** создавать базы данных и коллекции, переносить данные из реляционных таблиц в JSON-документы, настраивать вывод полей (проекции) и фильтровать данные с помощью операторов сравнения (`$gt`, `$lt`) и регулярных выражений (`$regex`).
